# ProofMesh

A lightweight Web3 identity and cryptographic proof toolkit.

ProofMesh allows users to generate a simple decentralized-style identity, create a public identifier, and generate cryptographic proofs for messages directly in the browser.

## Features

- 🔐 Generate a unique ProofMesh identity
- 🆔 Create a DID-style identifier
- 🔑 Generate a public identity key
- ✍️ Sign messages using SHA-256 cryptographic hashing
- 🛡️ Generate a verifiable message proof
- 🌐 Runs directly in the browser
- ⚡ No backend required
